# 🧵 ગારમેન્ટ લોટ વ કારીગર મેનેજર (Garment Lot & Karigar Manager Mobile Web App)

यह एप्लीकेशन खास तौर पर गारमेंट मैन्युफैक्चरिंग, टेलरिंग व जॉबवर्क के लिए बिल्कुल सरल (Simple, Clean & Mobile-Friendly) बनाई गई है ताकि कोई भी कारीगर या अनपढ़ व्यक्ति भी इसे मोबाइल पर आसानी से चला सके।

---

## ✨ मुख्य नए फीचर्स (Key Features)

1. 📱 **मोबाइल-फ्रेंडली डिज़ाइन (Mobile-First Experience)**:
   - ऐप मुख्य रूप से मोबाइल स्क्रीन के लिए तैयार की गई है (360px से 430px और टैबलेट/डेस्कटॉप सब पर परफेक्ट)।
   - सभी इनपुट व बटन अंगूठे से छूने के लिए बड़े आकार (44px - 48px) में हैं।
   - मोबाइल स्क्रीन पर ऑटो-ज़ूम की समस्या हल (Font-size $\ge 16\text{px}$).
   - नीचे मोबाइल बॉटम नेविगेशन बार (Home, Lots, +New Lot, Karigars, Master 🔐)।

2. 🎨 **हल्के रंग के प्लेसहोल्डर (Light Color Placeholders)**:
   - सभी इनपुट फील्ड्स में हल्के स्लेट/ग्रे कलर (`#94a3b8`) के प्लेसहोल्डर लगाए गए हैं ताकि फॉर्म देखने में साफ व आधुनिक लगे।

3. 📅 **डैशबोर्ड पर तारीख से सर्च/फिल्टर (Dashboard Date Range Filter)**:
   - **શરૂઆત તારીખ (From Date)** और **ખતમ તારીખ (To Date)** डालकर किसी भी तारीख का हिसाब तुरंत निकालें।
   - **क्विक फिल्टर बटन**: 
     - ⚡ **આજ (Today)**
     - ⚡ **કલ (Yesterday)**
     - ⚡ **ઇસ હફ્તે (This Week)**
     - ⚡ **ઇસ મહિને (This Month)**
     - ⚡ **સબ તારીખ (All Time)**
   - चुनते ही चारों कार्ड्स (व्यापारी से आय, कुल खर्च, शुद्ध मुनाफा और कुल लॉट) तुरंत अपडेट हो जाते हैं।

4. 🗄️ **परमानेंट SQLite डेटाबेस (Permanent SQLite Storage)**:
   - डेटा अब सुरक्षित SQLite डेटाबेस में हमेशा के लिए सेव रहता है: **`App_Data/garment.db`**
   - बैकअप के लिए ऑटोमैटिक JSON सिंक भी चालू रहता है: **`App_Data/garment_data.json`**

5. 🔐 **मास्टर मैनेजमेंट पासकोड (`123abc`)**:
   - व्यापारी, आइटम, कटिंग मास्टर और इंटरलॉक सेंटर जोड़ने/बदलने के पेज पासकोड से सुरक्षित हैं।

6. 🌐 **भाषा विकल्प (ગુજરાતી લિપિ / English)**:
   - गुजराती लिपि में हिंदी उच्चारण (જેમ કે: ડેશબોર્ડ, નયા લોટ, વ્યાપારી, કારીગર, મુનાફા) और टॉप पर English स्विच बटन।
   - व्यापारी और कारीगरों के नाम शुद्ध English में।

## 🌟 सरल 2-कदम प्रक्रिया (2-Step Workflow)

### 📌 कदम 1: नया लॉट जोड़ें (Create New Lot)
1. **તારીખ (Start & End Date)**: शुरू होने और खत्म होने की तारीख।
2. **કિસ્કા માલ હૈ? (Merchant Name)**: लिस्ट से नाम चुनें (Gupta Garments, R.K. Brothers आदि) या नया लिखें।
3. **ક્યા આઇટમ બનેગા? (Item)**: लिस्ट से चुनें (Shirt, Plazo, Pant, Kurti, T-Shirt आदि)।
4. **કલર (Color)**: रंग का नाम लिखें (उदा. Navy Blue, Black, White)।
5. **કિતને પીસ બનેંગે (Total Pieces)**: कोई डिफॉल्ट नंबर नहीं, खाली बॉक्स में पीस डालें (उदा. `450`)।
6. **એક પીસ કા ભાવ (Rate/Pc)**: व्यापारी से प्रति पीस मिलने वाला भाव डालें (उदा. `₹50`)।
7. **[ લોટ સેવ કરો ઔર કામ શુરૂ કરો ]** दबाएं।

---

### 📌 कदम 2: कटिंग, इंटरलॉक व कारीगर सिलाई दर्ज करें (Lot Work Process)
उसी लॉट के अंदर 3 साफ-सुथरे कार्ड्स हैं:
1. ✂️ **કટિંગ માસ્ટર**: लिस्ट से मास्टर चुनें (Master Aslam आदि) और रेट डालें (उदा. `₹2`).
2. 🪡 **ઇન્ટરલોક સેન્ટર**: लिस्ट से सेंटर चुनें (Babu Interlock आदि) और रेट डालें (उदा. `₹2`).
3. 🧵 **કારીગર સિલાઈ**: 
   - 6 कारीगरों के नाम सामने हैं (Ramesh Kumar, Salim Ansari, Abdul Kalam आदि)।
   - सिर्फ सामने पीस डालें। ऊपर लाइव काउंटर दिखाता है: **કુલ પીસ: 450 | સિએ ગયે: 450 | બાકી: 0**.
4. 💰 **લાઈવ મુનાફા બોર્ડ**:
   - 🟢 व्यापारी से मिलेंगे: **₹22,500**
   - 🔴 कटिंग वाले को: **₹900**
   - 🔴 इंटरलॉक वाले को: **₹900**
   - 🔴 कारीगरों को सिलाई: **₹13,500**
   - 🔴 कुल खर्च: **₹15,300**
   - 🟢 **મેરા મુનાફા: ₹7,200**

## 🚀 चलाने का तरीका (How to Run Locally)

1. फोल्डर में **`run_app.bat`** पर डबल-क्लिक करें।
2. मोबाइल या कंप्यूटर के ब्राउज़र में खोलें:
   **`http://localhost:5062`**

## ☁️ Firebase व Cloud पर होस्टिंग (Firebase Hosting Deployment)

यह एप्लिकेशन **Firebase Hosting** और **Cloud Run** के लिए पूरी तरह कंफिगर की गई है:
- **`firebase.json`**: Firebase Hosting रीराइट नियम।
- **`Dockerfile`**: कंटेनर इमेज जो सीधे Google Cloud Run / Firebase App Hosting पर चलती है।
- **`App_Data/garment.db`**: SQLite डेटाबेस फ़ाइल स्थायी वॉल्यूम या क्लाउड स्टोरेज पर सेव होती है।

### Firebase CLI से डिप्लॉय करने के कदम:
```bash
# 1. Firebase टूल्स इनस्टॉल करें (यदि पहले से नहीं है)
npm install -g firebase-tools

# 2. अपने गूगल खाते से लॉगिन करें
firebase login

# 3. प्रोजेक्ट इनिशियलाइज़ करें
firebase use --add

# 4. डिप्लॉय करें
firebase deploy
```
